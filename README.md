# 🐐 Focus Goat — Official Landing Page & Web

Sitio web oficial y página de aterrizaje de **Focus Goat**, la extensión de Google Chrome para máxima concentración, bloqueo de distracciones y rutinas de estudio.

---

## 🌐 Despliegue en Netlify (100% Gratuito)

Esta página web está lista para publicarse en **Netlify** en un clic conectando este repositorio de GitHub:

1. Inicia sesión en [Netlify](https://app.netlify.com/).
2. Haz clic en **"Add new site"** ➔ **"Import an existing project"**.
3. Selecciona **GitHub** y elige el repositorio `OliverRomeroCruz/focus-web`.
4. En los ajustes de despliegue:
   * **Branch to deploy:** `main`
   * **Build command:** *(dejar vacío)*
   * **Publish directory:** `.` *(raíz del proyecto)*
5. Haz clic en **"Deploy focus-web"**.

¡Tu página estará online en pocos segundos con HTTPS gratuito y dominio `.netlify.app`!
